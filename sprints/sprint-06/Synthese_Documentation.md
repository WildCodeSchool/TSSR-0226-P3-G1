## Remarques

Certaines machines visibles dans Proxmox correspondent à des serveurs applicatifs ou à des machines internes dont la documentation est répartie dans plusieurs composants GitHub.

Dans ce cas, la documentation n’est pas toujours rattachée à un nom de VM unique, mais plutôt au service installé ou configuré. Exemple :

- la documentation `VYOS` couvre les routeurs `R1`, `R2` et `R3` ;
- la documentation `Serveur_de_Messagerie` couvre le serveur mail ;
- la documentation `ATTAQUE_DEFENSE` couvre les scénarios réalisés depuis Kali, Snort et les serveurs cibles ;
- la documentation `AUDIT` couvre plusieurs serveurs ou applications audités ;
- la documentation d’architecture complète les machines qui n’ont pas une documentation dédiée par VM.
